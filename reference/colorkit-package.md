# colorkit: Tools for Color Display, Conversion, and Sampling

Utility functions for working with colors in R. Includes tools for
converting colors to hexadecimal strings, selecting contrasting
foreground colors for a given background, randomly sampling colors, and
displaying colors visually as plotted cells or printed console output.
